# Voevoda

## Описание
Одиночная игра с видом сверху в жанре RTS на Unreal Engine 4. Игрок управляет генералом на 2D карте(камера может перемещаться независимо от пользователя), может сражаться с другими генералами-ботами и пополять армию в городах.
- **Механика боя**: Реализованы модификаторы сражений, основанные на типах войск (пехота, кавалерия, лучники) и ландшафте местности.
- **Туман войны**: Динамическая система тумана войны с сохранением запоминанием ранее исследованных участков карты. Враги видны только вокруг армии пользователя и разведчиков
- **Разведчики**: игрок может выставлять ограниченное число разведчиков на карте. Они временно раскрывают туман войны вокруг и возвращаются к пользователю. 
 
В главном меню во вкладке **settings** игрок может создать аккаунт, или войти в существующий.

## Запуск проекта: 
- Скачать **[Unreal engine](https://www.unrealengine.com/en-US)**
- Скачать версию движка **4.27**
- Создать проект с именем **Voevoda** и скопировать в него файлы из ветки **main**
- Компиляция: обновить **Sourse/Voevoda.Build.cs** - библиотеки подгрузятся.
- Проставить в Blueprint классы для Strategist, PlayerCharacter, GameWorld.
- Обновить Blueprint-схемы
- Запустить **Crow** сервер
  - перейти в **httpServer**
  - запустить **./main** через консоль
